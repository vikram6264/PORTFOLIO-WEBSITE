# Vikram Patel — Developer Portfolio

A modern, premium developer portfolio built with React, Vite, Tailwind CSS, and Framer Motion.

## Live Demo

[https://your-domain.vercel.app]([https://your-domain.vercel.app](https://vikrampatel-02-6ldl6sh7p-vikram-patel.vercel.app/))

## Tech Stack

- **Frontend:** React 18, Vite
- **Styling:** Tailwind CSS v4
- **Animations:** Framer Motion
- **Routing:** React Router
- **Icons:** Lucide React, React Icons

## Getting Started

```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/portfolio.git

# Navigate to the project
cd portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

## Available Scripts

```bash
npm run dev       # Start dev server
npm run build     # Build for production
npm run preview   # Preview production build
```

## Deployment (Vercel)

1. Push to GitHub
2. Connect repo to Vercel
3. Vercel auto-deploys on every push
